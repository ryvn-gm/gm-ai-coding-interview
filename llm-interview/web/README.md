# LLM / 演算法面試・抽卡題庫（網站）

面試官專用的抽卡工具：隨機抽題、翻看詳解，引導一場「看思考、不看背誦」的對話。

## 怎麼開

直接用瀏覽器打開 `index.html` 就好（不需要架伺服器、不需要網路）：

```
雙擊 index.html   或   拖進瀏覽器   或   open index.html
```

## 功能

- **抽卡模式**：按「🎲 抽一張」隨機出題，先只顯示題目，按「翻看參考答案」再揭曉。抽卡不重複，直到該輪抽完才重新洗牌。
- **瀏覽全部**：列表瀏覽所有題目，點任一題直接看完整詳解。
- **篩選**：依回合（一面／二面）、難度（基礎／進階／深入）、主題（Transformer、RAG、Agent…）任意組合。
- **鍵盤**：`空白鍵`＝翻答案／抽下一張，`←`＝上一張，`Esc`＝關閉視窗。

## 每張卡片包含

題目（優化版）＋ 原題 ＋ 這題在考什麼 ＋ 多個切入角度 ＋ 多種參考答案 ＋ 可追問 ＋ 沒有標準答案的可辯論處 ＋ green/red flags。

> 參考答案是**寫給面試官的**，刻意比候選人需要回答的更完整。候選人答到其中幾個角度就很好，重點是看他怎麼想、怎麼追問、怎麼面對不確定。

## 檔案

| 檔案 | 作用 |
|------|------|
| `index.html` | 頁面結構 + 歡迎／指導頁 |
| `styles.css` | 樣式 |
| `app.js` | 抽卡 / 篩選 / 渲染邏輯 |
| `questions.js` | **題庫資料（唯一資料來源）** — 要改題目或答案改這裡 |

## 改題目

編輯 `questions.js` 裡的 `QUESTIONS` 陣列。每張卡的欄位說明寫在檔案最上方的註解。改完存檔、重新整理瀏覽器即可，不需要任何建置步驟。

題目的「優化前 → 優化後」與技術內容的查證來源，記錄在上一層的 `../BUILD-LOG.md`。
